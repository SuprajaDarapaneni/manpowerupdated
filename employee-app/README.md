# Employee & Worker Mobile Application (Flutter)

This is the independent Flutter mobile codebase for **Employees and Workers** in the ManPowerLink temporary manpower marketplace.

## Features
- **Job Discovery & Bidding**:
  - Discover nearby shifts filtered by category, location, and distance.
  - Review shift package details (approximate duration, fixed package or hourly rate per head).
  - Submit bids with custom notes.
- **Job Execution & Verification**:
  - Live shift details, location address, and client contact.
  - Start-Job OTP input to verify physical presence on site.
  - Job completion submission and earnings transfer.
- **Worker Wallet**:
  - Live balance, daily earnings breakdown, and instant payout withdrawal.

## Running the App
```bash
cd employee-app
flutter pub get
flutter run
```
