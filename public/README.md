# Public Directory (`/public`)

This directory is the standard static asset folder for the web application served directly by Vite. Files placed here are served as-is at the root URL path (unbundled and unmodified):

- `favicon.svg` - Official ManPowerLink SVG logo icon (Red `#D71920` with Gold `#FFC928` 'M' emblem).
- `manifest.json` - Progressive Web App and mobile browser metadata.
- `robots.txt` - Search engine crawler indexing guidelines.
- Any future static brand assets, images, or client documents.
